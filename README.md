# My Portfolio

3D animated personal portfolio (Three.js + vanilla JS/CSS).

## Structure
- `index.html` — page markup
- `css/style.css` — all styles
- `js/main.js` — content data (top of file), UI logic and 3D scenes

## Edit your content
Open `js/main.js` and change `CONFIG`, `PROJECTS`, `SKILLS` and `JOURNEY` at the top.

## Run locally
Open `index.html` in a browser (internet needed for fonts and Three.js CDN).

## Deploy
Push to GitHub, then Settings → Pages → Deploy from branch → main / root.
